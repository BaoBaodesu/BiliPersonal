# v0.3.2 实施与验收记录

实施日期：2026-10-04。P0–P3 已落地；策略准入和至少七天的人工试用仍需用户完成。试用初值不是已验证的推荐收益。

## 已实施

- P0：候选以 BVID 为唯一主体，来源、seed、query 和理由独立保存；完整详情保护、关系 TTL、共享主体清理、唯一评分、30 分钟跨推荐流冷却、提交前事务内重查、stream 与搜索分页防重。
- 后台：固定维护 `for_you/all` 和最近两个实际访问分类；分类保留 24 小时，空闲五分钟检查，低于两页补至三页，无成果退避十五分钟。池满停止垂类搜索。复用单进程启动和现有 Scheduler，Feed 不同步补池。
- 请求：实际发送准入计数，候选后台滚动一小时 240 次，搜索子预算 40 次；WBI/nav、重试和重定向纳入计数，采集历史／收藏独立标记。额度持久化失败停止发送；登录、登出不重置额度。
- 生命周期：`start_background=False` 贯穿登录、预取、模型回调和恢复入口；停止会话期间即使 Cookie 尚未清除也不能复活任务。
- P1：后台发布双画像快照，真实行为日期资格、14 天短期窗口、3 天半衰、每日 BVID 限幅；固定／暂停／排除、明确别名和标题匹配词；主动搜索记忆默认关闭。
- 垂类：默认关闭，主题轮转，最多六个长期／显式与两个短期方向，每 query 每小时两页；失败不立即换 query，结果后台补详情后进入共享池，自动查询不成为行为证据。
- 特别关注：关注原始响应与候选专用 GET 接口只读同步，本地设置优先，失败保留上次成功状态；扩展旧作资格与手动查询，不改变 regular 判定。
- 收藏：普通／工具学习／支持作者用途与训练 Label 分离；显式允许回看的收藏按 7／30 天冷却、每页最多一条，硬过滤与 30 分钟底线仍生效。撤销许可或新发生已看行为会立即作用于缓存页。
- P2：模型外规则分、作者频率、每页作者上限、探索与纯短期上限、长期覆盖目标、旧作权重和 Top4；保留原 rating，空评分降级不伪造预测。stream 冻结参数和画像，位置快照保存主／辅助归因。
- P3：扩展设置页与兴趣页的 7／30 天来源、主题、UP、query 分析；真实曝光分母、零分母空值、历史快照解释。点击率明确为代理指标。
- 独立策略 Top12／Top4 盲评捕获、报告和人工试用准入；与已有模型试用互斥，改变模型或核心参数后要求重新验证，不自动切换活动模型。
- 原生四档滑杆：释放后保存、键盘完成后保存、取消不保存、失败恢复、保存期间禁重复提交、保存后恢复键盘焦点。保留用户原有未提交改动。

### 升级与结构回滚

先停止服务，在项目根目录执行：

```powershell
.venv\Scripts\python.exe -m backend.tools.candidate_migration upgrade
.venv\Scripts\python.exe -m backend.tools.candidate_migration downgrade
```

每次命令均先备份和演练。降级从当前主体与关系重建旧候选表，保存降级前关系备份，不恢复整库，不丢弃新增反馈和曝光。结构降级后需切回兼容旧结构的代码再启动；新版启动检测到旧结构会明确报错。

规则回滚使用设置页“关闭策略”；垂类召回单独关闭来源。人工设置、历史、反馈和旧 stream 快照保留。经典首页开关继续可用。

## 接口与操作

保留旧字段与模型发布协议，增量提供：

| 接口 | 用途 |
|---|---|
| GET/PUT `/api/v1/system/sources` | 原档位及默认关闭的 vertical_search |
| GET `/api/v1/user/interests?days=7或30` | 旧统计、双画像及位置归因分析 |
| GET/PUT `/api/v1/user/interest-settings` | 主题、别名、query、搜索记忆、特别关注本地设置 |
| GET `/api/v1/user/video-preferences` | 收藏用途与回看设置 |
| PUT `/api/v1/user/video-preferences/<bvid>` | 普通／工具／支持，回看许可和周期 |
| GET/POST/DELETE `/api/v1/user/search-history` | 主动搜索事件 ID 防重与删除 |
| GET/PUT `/api/v1/system/recommendation-settings` | 兴趣增强、探索、旧作档位 |
| GET/POST `/api/v1/system/policy-trial` | 状态、start／keep／stop |
| GET `/api/v1/feed/explain/<bvid>?recommendation_id=...` | 对应历史位置的冻结解释 |

设置页控制来源与策略；兴趣页维护人工主题、别名、query、特别关注及搜索记忆；收藏页逐视频维护用途与回看。

### 人工准入

保持模型和参数不变，在五个不同候选更新批次分别停止服务捕获：

```powershell
.venv\Scripts\python.exe -m backend.tools.policy_review capture
.venv\Scripts\python.exe -m backend.tools.policy_review report
```

捕获命令返回独立策略 `rating.json` 路径；用户填写每视频 -1／0／1／2／3 分。每批必须具备完整 Top12，不用短页补造样本。报告通过后在设置页手动启动试用，至少七天后人工保留、延长或关闭。未完成评分或护栏未通过时禁止启动。当前未捕获五批、未填写人工评分、未进行七天试用。
